# PRD: 개발자 면접 준비 앱 (my_app)

## 목표

개발자가 분야별 개념/문제를 서술형으로 학습하고, 자신의 이력서를 기반으로 AI와 실제 면접처럼 대화하며 준비할 수 있게 한다.

## 사용자

기술면접을 준비하는 개발자(취업/이직 준비생).

## 핵심 기능

1. 분야별(카테고리) 서술형 문제 학습 — "학습하기"(모범답안을 바로 보는 읽기 전용 모드)와 "문제풀기"(답변 작성 → 모범답안 확인 → 정답/오답 자가 채점 → 오답노트 저장) 2가지 방식 제공. 홈 화면에서 분야를 카드 UI로 선택(각 분야마다 고유 아이콘)
2. 이력서(PDF/텍스트) 업로드 기반 AI 모의면접 — LLM과 대화형으로 면접 진행
3. OAuth 회원가입(Google/GitHub/Kakao) — 비회원은 모의면접 사용량 하루 소량 제한, 회원가입 시 더 넉넉한 무료 한도. 각 플랫폼별로 최적 로그인 방식 적용(Google은 모바일 네이티브, 나머지는 리다이렉트). Apple 로그인은 제거했다(ADR-022)
4. (어드민) 자료 수집 → AI 문제 초안 생성 → 중복 비교 → 관리자 승인 → 게시하는 콘텐츠 파이프라인

## MVP 제외 사항

- 결제/구독(무제한 이용권) — 스키마만 대비, 실제 결제 연동은 하지 않음
- 완전 자동화된 웹 자료 수집 — 1차는 관리자가 원문을 직접 입력
- 면접관 음성 대화(TTS/STT) — 텍스트 대화로 시작

## 디자인

- Material 3 기본 테마 + 시드 색상 하나를 사용하고, 라이트/다크 모드를 모두 지원한다.
- 본격적인 커스텀 디자인(색상, 타이포그래피, 컴포넌트 커스터마이징)은 M2 이후에 진행한다.

## 성공 기준

- Android/iOS/Web 세 플랫폼에서 카테고리 문제풀이 → 오답노트 → 이력서 업로드 → 모의면접까지 전체 여정이 동작
- 비회원/회원 사용량 제한이 실제로 구분되어 적용됨
- `LLM_PROVIDER` 값 변경만으로 Anthropic ↔ OpenAI 전환 가능

## 확정 사항 (M5-a, 2026-09-20)

- 콘텐츠 수집 1단계의 자료 소스: 관리자 수동 입력 (M5-a)
- 어드민 웹앱 프레임워크: Vite + React + TypeScript (Tailwind v4 + shadcn/ui)

## 확정 사항 (M4 이후 후속, 2026-09-21)

- Kakao OAuth 지원 — 전 플랫폼 리다이렉트 (ADR-018). Apple 로그인은 2026-10-01에 제거 (ADR-022)
- 홈 분야 카드 UI의 아이콘: DB 컬럼 없이 Flutter 앱 코드의 `slug → IconData` 매핑으로 처리. 새 분야 추가 시 앱 배포 필요
- Kakao 로그인 시 이메일 미필수 가입 허용 (최종 확정은 출시 후 사용자 데이터로 재검토)
- 딥링크 스킴 값은 이번 작업(Apple/Kakao 로그인) 계획 단계에서 확정 예정

> M2에서 분야별 카테고리 목록과 문제 콘텐츠 범위를 정함: CS · 프론트엔드 2개 분야, 각 분야당 주제 2개 · 문제 3개(서술형만). 전체 분야 확정은 이후 마일스톤에서.

기술 설계와 마일스톤은 `docs/architecture.md`, `docs/roadmap.md` 참고.

## 확정 사항 (2026-10-01)

- 로그인은 카카오·구글·깃허브 3개 (ADR-022). 카카오는 비즈 앱 + 닉네임(필수)·프로필 사진(선택)·이메일(선택) 동의항목이 모두 설정돼야 한다
- 모의면접 시작: 지원 분야 선택을 없애고 지원 직무(필수) + 회사 채용공고(선택)로 시작. 이력서의 자기소개를 저장해 "자기소개로 시작하기"로 첫 답변으로 보낼 수 있다 (ADR-023)
- 모의면접·문제풀기에 음성 입력(마이크), 웹·앱 화면 모드(라이트/다크, 기본 라이트) 제공
- 이력서 PDF는 최대 4MB·20페이지 (Vercel 요청 본문 4.5MB 한도)
- 콘텐츠: 분야 7개(CS·프론트엔드·백엔드·AI·모바일·인프라/DevOps·ML·모델), 게시 문제 548개 (2026-10-01 기준)

## 확정 사항 (2026-10-04)

- 첫 출시는 iOS 앱스토어 + 웹. Android 스토어 출시는 이후 (ADR-025)
- 첫 출시 로그인은 카카오·깃허브 + Apple(iOS 앱에서만). 구글 로그인은 숨겼다가 앱·웹 모두 복원한다 (ADR-025 정정, ADR-022 정정)
- 회원은 앱 설정 화면·웹 내 정보에서 계정을 즉시 삭제할 수 있다. 계정에 저장된 오답노트·이력서·면접 기록이 함께 지워지고 복구할 수 없다 (ADR-026)
- 모의면접을 처음 시작할 때 OpenAI(미국) 전송 동의를 받는다. 동의하지 않아도 문제풀이·오답노트·이력서는 쓸 수 있다 (ADR-027)
- 개인정보처리방침·이용약관은 웹 `/privacy`·`/terms`. 운영자는 개인 개발자로 표기한다
- 학습하기 문제 목록은 난이도(쉬움/보통/어려움)로 걸러 볼 수 있다
- 비회원 사용량 카운터는 30일 뒤 자동 삭제한다
