```

답을 직접 써 보고, 모범답안과 비교하고, 내 이력서로 면접을 연습합니다.
```

## 심사 메모 (App Review Information > Notes)

```
1. 로그인 없이 모든 기능을 쓸 수 있습니다.
   문제풀이, 오답노트, 이력서 입력, AI 모의면접 모두 비회원으로 동작합니다.
   비회원은 하루 모의면접 메시지 수가 제한됩니다.

2. 로그인 (내 정보 탭 > 로그인)
   Apple로 로그인, 카카오, Google, GitHub을 제공합니다.
   별도 테스트 계정은 필요하지 않습니다. 회원 기능은 Apple로 로그인해 확인할 수 있습니다.

3. 회원탈퇴 = 계정 삭제 (가이드라인 5.1.1(v))
   내 정보 탭 맨 아래 "회원탈퇴" (또는 오른쪽 위 톱니바퀴(설정) > 회원탈퇴).
   확인 후 즉시 삭제되며 계정의 오답노트·이력서·면접 기록이 함께 지워집니다.
   Apple로 로그인한 계정은 삭제 전에 Apple 인증을 한 번 더 받고 토큰을 철회합니다.

4. 제3자 AI 전송 동의 (가이드라인 5.1.2(i))
   모의면접 탭에서 처음 "면접 시작"을 누르면 동의 화면이 나옵니다.
   이력서·채용공고·대화 내용이 OpenAI(미국)로 전송된다는 점을 알리고 동의를 받습니다.
   동의하지 않으면 모의면접만 쓸 수 없고 나머지 기능은 그대로입니다.

5. 마이크·음성 인식 권한
   모의면접과 문제풀기의 답변 입력창에서 마이크 버튼을 누를 때만 요청합니다.
   인식된 글을 입력창에 채우는 용도이고, 음성을 우리 서버로 보내지 않습니다.

6. 개인정보처리방침·이용약관
   설정 화면과 로그인 화면에서 열 수 있습니다.
```

데모 계정: 비회원으로 전 기능을 쓸 수 있어 필수는 아니다. 심사자가 회원 기능을 보려면 Apple 로그인을 쓰면 된다.

## App Privacy 라벨

`ios/Runner/PrivacyInfo.xcprivacy`, `/privacy`와 같은 내용으로 입력한다. 추적(Tracking)은 "아니요".

| 데이터 유형 | 수집 | 사용자와 연결 | 목적 | 근거 |
|---|---|---|---|---|
| 연락처 정보 > 이메일 주소 | 예 | 예 | 앱 기능 | 소셜 로그인 프로필 |
| 연락처 정보 > 이름 | 예 | 예 | 앱 기능 | 소셜 로그인 프로필(표시 이름) |
| 식별자 > 사용자 ID | 예 | 예 | 앱 기능 | 계정 ID |
| 식별자 > 기기 ID | 예 | 아니요 | 앱 기능 | 비회원 사용량 한도용 임의 ID(광고 ID 아님) |
| 사용자 콘텐츠 > 기타 사용자 콘텐츠 | 예 | 예 | 앱 기능 | 이력서, 자기소개, 채용공고, 면접 대화 |
| 사용 데이터 > 제품 상호 작용 | 예 | 예 | 앱 기능 | 일일 면접 사용량 카운터 |

- 오디오 데이터: 음성 인식은 기기·Apple이 처리하고 우리 서버로 보내지 않으므로 "수집 안 함"으로 둔다(방침에는 Apple 처리 가능성을 적어 둠).
- 광고·분석 SDK 없음.

## 스크린샷

첫 출시는 iPhone 전용이다(`TARGETED_DEVICE_FAMILY = 1`, 2026-10-08 결정). iPad 화면을 확인하지 못했고 iPad 스크린샷도 필요해지기 때문이다. iPhone 스크린샷만 올리면 된다. iPad 사용자는 iPhone 앱을 확대해 쓸 수 있다.

권장 장면(순서대로):

1. 홈 — 분야 카드
2. 문제풀기 — 답변 작성 화면
3. 모범답안 비교·자가 채점
4. 오답노트 목록
5. 모의면접 대화 화면
6. 이력서 입력(PDF 불러오기)

시뮬레이터에서 `flutter run --dart-define-from-file=env/prod.json`으로 띄워 찍는다. 상태 표시줄 시간·배터리는 그대로 둬도 된다.
